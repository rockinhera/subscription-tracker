# Subscription Tracker

A simple subscription tracker built with **ReactJS** and **Tailwind CSS**.

## Live Preview

[View Live Website](https://rockinhera.github.io/subscription-tracker/)

## Features:

* Add new subscriptions.
* Edit existing subscriptions
* Delete subscriptions.
* Choose a subscription category.
* Calculate monthly subscription total.
* Responsive design.

## Technologies Used:

* ReactJS
* Tailwind CSS
* Vite
* JavaScript

## Project Preview:

A simple dashboard for keeping track of monthly subscriptions and their costs.
